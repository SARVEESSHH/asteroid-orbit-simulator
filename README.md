# ☄️ Asteroid Orbit Simulation

A physics-based astronomy project that simulates asteroid
orbits using real orbital parameters.

## Objects Studied
- Earth
- 4 Vesta
- 1 Ceres

## Methods
- Orbital mechanics
- Kepler's Laws
- Numerical visualization

## Results
The simulation successfully reproduced the elliptical
orbits of Earth and two main-belt asteroids.

## Tools
- Python
- NumPy
- Matplotlib
